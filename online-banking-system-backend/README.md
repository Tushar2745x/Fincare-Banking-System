MYSQL FAQs:

Do I need to create database and table manually?

NO, you don't have to create the Database and Tables manually in the MySQL Server. When you run the backend application
for the first time it automatically
creates the Database and Tables in the MySQL server.

You just have to enter the correct mysql password in application.properties file and make sure MySQL Server is properly
installed in your system.
