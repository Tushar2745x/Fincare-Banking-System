# Fincare-Banking-System

Full-stack online banking application with Spring Boot backend and React frontend.

## Project Structure

- `online-banking-system-backend` — Java Spring Boot REST API
- `online-banking-system-frontend` — React (Vite) web application

## Getting Started

### Backend

```bash
cd online-banking-system-backend
./mvnw spring-boot:run
```

### Frontend

```bash
cd online-banking-system-frontend
npm install
npm run dev
```
